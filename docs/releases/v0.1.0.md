# Ruleproof 0.1.0

Ruleproof finds the places where the instructions you give coding agents stop
telling the truth.

## Included

- Scans AGENTS.md, CLAUDE.md, GEMINI.md, Cursor rules, Windsurf rules, Cline
  rules, and GitHub Copilot instruction files.
- Detects package manager, formatting, path ownership, test command, and commit
  policy conflicts across files.
- Validates package scripts, Make targets, just recipes, script files, and
  referenced repository paths.
- Audits MCP server configuration for invalid JSON, unpinned packages,
  plaintext HTTP, unsafe commands, and machine-bound paths.
- Finds credentials, private keys, prompt injection, destructive commands, and
  hard-coded local paths.
- Reports approximate token cost and duplicate instructions.
- Outputs terminal, JSON, Markdown, GitHub annotations, SARIF, standalone HTML,
  and SVG score badges.
- Ships as a zero-runtime-dependency GitHub Action.

## Try it

```bash
npx --yes github:stilburn007/ruleproof .
```

```yaml
- uses: stilburn007/ruleproof@v1
  with:
    fail-on: error
```

The repository's intentionally broken payments API demo scores 56/100 and
reports two errors and two warnings.
